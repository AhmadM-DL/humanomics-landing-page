Privacy policy

Your notebooks stay yours.

Last updated: October 17, 2026

Humanomics never sends your code. With your consent, it shares only anonymized save times, code sizes and numbered authors, to tune its metrics.

Humanomics is a browser extension that analyzes the revision history of the Google Colab notebook open in your current tab. This page explains what it reads, what it keeps, and what it sends.

What Humanomics reads

When you click the Humanomics icon on a Colab notebook, Humanomics asks Google Drive for the notebook's list of saved versions through Colab's own signed-in connection: each save's time, author name and email, and file size. If Drive can't be reached, it can instead read the dates and names shown in Colab's File → Revision history list.

To measure code size, Humanomics downloads each revision once through the same Colab session and counts the bytes of code and text in its cells. The notebook contents are read in your browser and discarded straight away. Only the byte count is kept.

What stays on your device

The following are stored in your browser's local extension storage and never leave your device:

  • the revision list (save times, author names and emails, file sizes)
  • the code size of each revision
  • whether you agreed to the anonymized statistics

You can remove them at any time by removing the extension.

What is sent, with your consent

To tune its metrics, Humanomics sends anonymized statistics for each notebook it analyzes. The first time you open it, Humanomics shows what is shared and asks you to agree. It asks only once. If you don't agree, it closes without reading anything, and nothing is sent. If you no longer agree, remove the extension.

For each checkpoint it sends:

  1. the seconds since the notebook's first checkpoint (no real dates)
  2. the code size in bytes
  3. the author as a number (1, 2, 3…), never a name or email

It also sends the extension version, whether the data came from Colab's revision data or the on-screen list, and a one-way hash of the notebook's file ID so the same notebook isn't counted twice. The hash can't be turned back into the file ID.

It never sends notebook names, author names, emails, Drive file IDs, revision IDs, real dates, scores, or any code or other notebook contents.

The statistics are stored in a Supabase database run by the developer and are used only to calibrate Humanomics. They are not sold, shared with third parties, or used for advertising.

What Humanomics doesn't do

  • No account, sign-in or API key.
  • No tracking or advertising, and no analytics beyond the statistics above.
  • It runs only on Google Colab pages.
