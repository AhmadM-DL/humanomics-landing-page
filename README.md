# humanomics-landing-page

Landing page and privacy policy for the Humanomics browser extension, served with GitHub Pages.

- `index.html`: landing page
- `privacy.html`: privacy policy (the URL given to the Chrome Web Store)
- `site.css`, `assets/`: styles, logo, fonts (SIL Open Font License, see `assets/OFL-*.txt`) and dashboard screenshots

Live at https://ahmadm-dl.github.io/humanomics-landing-page/

Questions about the extension or its privacy policy: open an issue here.
